# 🐍 Snake Game

## 📌 Description
A classic Snake Game developed using Python and Tkinter.

## ✨ Features
- Keyboard Controls
- Score Counter
- Food Generation
- Collision Detection
- Game Over Screen

## 🛠 Technologies Used
- Python
- Tkinter

## ▶️ Run

```bash
python snake_game.py
```

## 🎮 Controls
- ⬆ Up
- ⬇ Down
- ⬅ Left
- ➡ Right
